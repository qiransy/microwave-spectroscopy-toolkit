# Microwave Rotational Spectroscopy Zotero Profile

仅在整理微波转动光谱（FTMW / CP-FTMW）相关文献库时选用本标签与笔记规范。

## 推荐标签体系

- `体系：` 分子体系、团簇或同位素体（如 `体系：水团簇`）
- `实验：` 实验方法（如 `实验：CP-FTMW`、`实验：cavity FTMW`）
- `证据：` 关键证据类型（如转动常数、偶极选律、同位素取代、超精细分裂、拟合残差）
- `计算：` 电子结构方法或构象搜索方法
- `状态：待获取全文`、`状态：全文已核查`、`状态：深度精读`

## 证据边界内的笔记字段

仅在已读来源实际支持的证据层级内记录以下字段：
- 转动常数 $A, B, C$
- 偶极矩分量 $|\mu_a|, |\mu_b|, |\mu_c|$
- 离心畸变常数
- 超精细参数（核四极耦合张量等）
- 同位素体信息
- 理论计算层级与构象拓扑
- 指认依据与未决问题

精确数值、原文引语和页码级论断须以核查过的全文或深度精读为依据。
